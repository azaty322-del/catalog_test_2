# Каталог контента UTV Media

Frontend каталога документального и научно-популярного контента.

## Запуск

Нужен Node.js 18.17 или новее.

```bash
npm install
npm run dev
```

Сайт откроется на http://localhost:3000

```bash
npm run build      # производственная сборка
npm run start      # запуск собранной версии
npm run typecheck  # проверка типов
```

Если после распаковки архива `npm run dev` отвечает `Permission denied`,
выполните `chmod +x node_modules/next/dist/bin/next` или переустановите зависимости.

## Стек

Next.js 14 (App Router), TypeScript, Tailwind CSS, Lucide Icons, Framer Motion.

## Обновление каталога

Каталог хранится только в PostgreSQL. Обновить его можно в админке:
вручную или через «Импорт Excel».

Импорт понимает два формата: собственный экспорт админки и таблицу заказчика
(лист = категория, колонки «Название … АЙДИ»). Записи сопоставляются по ID или
шифру АЙДИ, пустые ячейки не затирают данные, заполненные в админке (английские
названия, постеры, теги). Разбор форматов заказчика — в `lib/excel.ts`: год и
эпизоды бывают диапазонами («2020-2024», «15-23»), общая длительность — временем
Excel («51:20:05») или округлённым числом часов.

## Структура

```
app/[locale]/        маршруты, язык в адресе: /ru/... и /en/...
components/ui/       UI Kit
components/shared/   Header, Footer, RouteGuard, поиск
components/features/ movies, filters, cart, account, admin
lib/catalog.ts       сервисный слой доступа к данным
lib/filters.ts       конфигурация фильтров и разбор URL
lib/auth/            авторизация, сессии в HttpOnly-cookie
lib/excel.ts         импорт и экспорт Excel
middleware.ts        запись в /api — только ADMIN
i18n/                словари интерфейса ru/en
prisma/              схема БД
scripts/seed.js      начальные настройки
```

## Данные и доступ

Единственный источник данных — PostgreSQL (`DATABASE_URL`): каталог, заказы,
пользователи, настройки и журнал аудита. Доступ к каталогу — через `lib/catalog.ts`.

Администратор задаётся в `.env`: `ADMIN_EMAIL` и `ADMIN_PASSWORD`. Имя и должность
подтягиваются из записи в таблице `User` с тем же email, если она есть.
Сессии подписываются `SESSION_SECRET`; при его смене все сессии сбрасываются.

## Реализованные функции

- **Каталог и поиск**: мгновенная фильтрация по категориям, качеству, хронометражу, годам и текстовый поиск.
- **Двуязычность (i18n)**: полная поддержка русского и английского языков (`/ru` и `/en`), включая автоматический перевод названий фильмов.
- **Корзина и Шаринг**: оформление заявки с контактами, а также функция **«Поделиться корзиной»** по ссылке (`?items=...`) с автозагрузкой у получателя.
- **Система заказов**: сохранение в базе, карточки заявок со статусами (*Новый / В обработке / Выполнен / Отменен*).
- **Админ-панель**: управление контентом, каталог, заказы и настройки.
- **Уведомления**: отправка уведомлений о заказах в Telegram-бот и на Email, настройка и тест бота прямо из панели администратора.
- **Безопасность**: защита паролей через PBKDF2 SHA-512, безопасные HttpOnly-куки, изоляция секретов через `.env`.
